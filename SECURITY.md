# Security and privacy

Shotdown is designed to run locally. Chat screenshots and generated PDFs are written only to the user's computer. The application does not include telemetry or an upload service.

The persistent browser profile under `~/.shotdown/browser_profile` can contain an authenticated WhatsApp Web session. Treat that folder as sensitive. Do not share or commit it.

If you discover a security issue, report it privately to the repository maintainer. Never post cookies, browser-profile files, private chats, or session data in a public issue.
