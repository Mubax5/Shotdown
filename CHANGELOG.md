# Changelog

## 0.2.0 — 2026-10-02

- Renamed the public product to **Shotdown**.
- Rebuilt the desktop interface with a restrained, neutral visual system.
- Added white-dominant light mode and dark-gray dark mode.
- Added persistent theme preference.
- Kept capture and export controls separated to reduce clutter.
- Moved local app data to `%USERPROFILE%\.shotdown`.
- Updated the Windows build output to `Shotdown`.
- Added CI tests and Windows build automation.

## 0.1.0

- Initial long-chat capture pipeline.
- WhatsApp Web scroll-container detection and history loading.
- Viewport capture with overlap handling.
- Adaptive 2–3 part PDF export with a strict per-file size cap.
